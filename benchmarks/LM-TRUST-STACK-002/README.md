# LM-TRUST-STACK-002

Status: **Implemented / pending execution receipt**

## Question

Under equal information and capability, does the LM reference runtime retain a
decision-relevant advantage over a conventional dependency/policy runtime after:

1. composition;
2. agent handoff;
3. projection/loss;
4. authority mutation;
5. evidence mutation;
6. dependency mutation?

## Outputs

Each arm must identify:

- current eligibility by operation;
- stale/invalid descendants;
- decision-relevant handoff/projection loss;
- minimal reopening set;
- unaffected nodes that remain closed.

No score is privileged. Parity is retained as a null result.

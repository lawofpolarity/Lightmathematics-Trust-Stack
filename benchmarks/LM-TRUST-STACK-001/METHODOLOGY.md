# LM-TRUST-STACK-001 Methodology

This first execution is intentionally conservative.

It compares the implemented LM local contract against an equal-information conventional deterministic reference for four properties:

1. rollback detection;
2. incompatible-snapshot/mix-and-match detection;
3. external-trust semantic non-escalation;
4. conservation of unresolved obligations across transitions.

Twenty-five cases are generated for each family: 100 total.

This is not yet a live interoperability benchmark against deployed SCITT, Rekor, EAS, ERC-8004, C2PA, AP2, or x402 infrastructure. Those require separately configured external execution.

A zero residual difference is a null result for LM-specific advantage and must be retained.

# Ethereum Attestation Service Integration Note

EAS is an optional public/off-chain attestation layer for LM-defined schemas.

Potential schemas:

- LM Reliance Attestation v1
- LM Transition Attestation v1
- LM Experiment Result Attestation v1
- LM Agent Handoff Attestation v1

An EAS attestation states that an attestation was made. It does not by itself
establish the substantive correctness of the attested content.
